# 20k 前端面试复习计划表（1-2 个月）

---

## 📌 **阶段一：核心基础冲刺（第 1-2 周）**  
**目标**：建立完整知识体系框架，补足基础短板  

### **每日学习计划**  

| 时间       | 学习内容                                | 学习方式与重点                                                                 |
|------------|---------------------------------------|------------------------------------------------------------------------------|
| **Day 1-3** | ⭐ **JavaScript 深度**                 |                                                                              |
|            | - 手写 Promise、防抖/节流、深拷贝        | 手写代码 + 理解设计思想（重点：异步流程控制）                                   |
|            | - 闭包、原型链、Event Loop 高频考点      | 结合流程图和面试题强化记忆（画图理解执行上下文）                                |
| **Day 4-5** | ⭐ **Vue 核心原理**                     |                                                                              |
|            | - 响应式原理（Proxy vs defineProperty） | 手写简易响应式系统（Proxy 实现 getter/setter）                                 |
|            | - Diff 算法优化点与虚拟 DOM 源码分析      | 阅读 Vue3 源码解析文章（重点：最长递增子序列）                                  |
| **Day 6-7** | **浏览器与网络**                       |                                                                              |
|            | ⭐ 从输入 URL 到页面渲染的完整过程        | 分步骤绘制流程图（DNS→TCP→渲染树合成）并口述                                   |
|            | - HTTP/2、HTTPS、WebSocket 核心机制      | 对比分析特性与使用场景（如：WebSocket 如何实现实时通信）                        |

### **每日任务**  
1. ✅ 完成 2-3 道 LeetCode 简单/中等算法题（重点：数组、字符串）  
2. ✅ 整理一道高频面试题答案（如：[Vue 组件通信方案大全](#)）  

---

## 📌 **阶段二：工程化与高阶能力（第 3-4 周）**  
**目标**：突破技术瓶颈，掌握架构设计思维  

### **每日学习计划**  

| 时间        | 学习内容                              | 学习方式与重点                                                                 |
|-------------|-------------------------------------|------------------------------------------------------------------------------|
| **Day 1-3** | ⭐ **前端工程化**                     |                                                                              |
|             | - Webpack 构建优化（Tree-shaking、缓存） | 配置优化项目（使用 SpeedMeasurePlugin 分析耗时）                               |
|             | - Vite 核心原理与竞品分析               | 阅读 Vite 官方文档 + 源码解析（ESM 预编译机制）                                |
| **Day 4-5** | **性能优化实战**                      |                                                                              |
|             | ⭐ 首屏加载时间从 5s 优化到 1s 的完整方案 | 结合 Lighthouse 分析报告（实操：代码分割、CDN、预渲染）                         |
|             | - 内存泄漏定位与解决（Chrome DevTools） | 实战模拟内存泄漏场景（Detached DOM 排查）                                      |
| **Day 6-7** | **TypeScript 进阶**                  |                                                                              |
|             | ⭐ 泛型、装饰器、工具类型高级用法         | 手写类型体操题目（如：实现 `PartialByKeys<T, K>`）                             |
|             | - Vue3 + TS 项目类型安全最佳实践        | 改造现有 JS 项目为 TS（定义组件 Props 类型）                                   |

### **每日任务**  
1. ✅ 研究一个开源库源码（如：Vueuse 的 `useFetch` 实现）  
2. ✅ 模拟回答设计类问题（如：如何设计前端监控系统？）

## 📌 **阶段三：项目包装与模拟面试（第 5-6 周）**  
**目标**：将项目经验转化为面试亮点，提升临场表现  

### **每日学习计划**  

| 时间        | 学习内容                              | 学习方式与重点                                                                 |
|-------------|-------------------------------------|------------------------------------------------------------------------------|
| **Day 1-3** | ⭐ **项目深度复盘**                   |                                                                              |
|             | - 提炼 2-3 个技术难点及解决方案         | 使用 STAR 法则描述（如：**S**ituation→**T**ask→**A**ction→**R**esult）         |
|             | - 量化项目成果（性能提升 40%）           | 准备可视化数据（如：Lighthouse 对比报告截图）                                  |
| **Day 4-5** | **系统设计能力**                      |                                                                              |
|             | ⭐ 设计一个微前端架构方案                | 对比 qiankun、Module Federation（实现原理、通信机制）                          |
|             | - 权限系统设计（路由 + 按钮级控制）       | 绘制架构图（RBAC 模型设计）                                                   |
| **Day 6-7** | **全真模拟面试**                      |                                                                              |
|             | - 技术面：同行模拟面试                   | 录音复盘卡顿点（如：源码题表述不清）                                           |
|             | - 行为面：准备"职业规划"标准答案          | 针对不同公司调整话术（如：大厂强调技术深度，中小厂突出全栈能力）                 |

### **每日任务**  
1. ✅ 整理项目难点思维导图（工具：XMind）  
2. ✅ 白板编码练习（重点：二叉树遍历、发布-订阅模式）

## ⚠️ **避坑指南**  
1. **忌广撒网**：优先攻克目标公司技术栈（如：若面阿里，重点准备 React + 低代码）  
2. **忌背答案**：用项目经验解释原理（如：Vue 响应式 → 结合项目优化案例）  
3. **忌过度设计**：系统设计题先确认需求边界（如：先问清楚用户量级再设计方案）  

---

**📌 最终目标**：  
- 技术回答体现**深度**（Why > What）  
- 项目描述突出**价值**（数据量化 + 业务影响）  
- 行为问题展现**稳定性**（职业规划清晰，无跳槽风险）
